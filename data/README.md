# Data

## `books/`: formal class (included)

Five French classics from [Project Gutenberg](https://www.gutenberg.org/), all in the public domain. Gutenberg headers and license text were removed, so only the original text remains.

| File | Work |
|---|---|
| `FleursDuMal.txt` | Charles Baudelaire, *Les Fleurs du mal* (1857) |
| `MadameBovary.txt` | Gustave Flaubert, *Madame Bovary* (1857) |
| `Miserables.txt` | Victor Hugo, *Les Misérables* (1862) |
| `MonteCristo.txt` | Alexandre Dumas, *Le Comte de Monte-Cristo* (1844) |
| `RougeEtNoir.txt` | Stendhal, *Le Rouge et le Noir* (1830) |

## `subtitles/`: informal class (not included)

French subtitles of four French films and one TV episode. They are copyrighted, so they are **not** in this repository. To run the notebook, download French `.srt` files for them (for example from [OpenSubtitles](https://www.opensubtitles.org/)) and save them under these names:

| File | Source |
|---|---|
| `Asterix.srt` | *Astérix & Obélix : L'Empire du Milieu* (2023) |
| `Bronzes.srt` | *Les Bronzés font du ski* (1979) |
| `Intouchables.srt` | *Intouchables* (2011) |
| `Negociateur.srt` | *Le Négociateur* (TF1 series, 2024), season 1, episode 1 |
| `Tuches.srt` | *Les Tuche* (2011) |

Different subtitle versions give a slightly different informal set, so results may differ a little from the README.
